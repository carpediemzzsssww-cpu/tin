所有预设均使用原创资产。完整搭配以人工编排为基础，只做小幅变化。「换一盒」替换整套外观、标题和摆放，照片库保留，可撤销还原；「随手抓」只添 3 件同一色系的小物，保留现有作品。照片可以盖在纸件上，继续自由叠放。

定制与导出

  • 「风格 → 配色」：六类桌面、桌面与纹样颜色、盒身颜色、四种内衬及内衬配色。
  • 「风格 → 排版」：名称、花体 / 中文手写 / 书刊 / 打字机、标题颜色、字号、倾斜、位置、说明、装饰、竖版或方形。
  • 选中物件「…」只展开相关的款式、配色、尺寸与内容。另一页「叠放顺序」可从列表选中被遮住的物件，上移 / 下移一层或移到最上 / 最下。
  • 纸件按用途提供字段：小票店名与清单、信封收寄件人、旅馆名与房号等。旅行画片支持替换照片，胶片三格可分别选择照片。
  • 设置内「清空物件」二次确认后移除当前摆放，保留照片库、配色与可撤销记录。
  • 预览与 PNG 共用场景与排版，预览不修改作品的开合状态。字体等待加载后导出，均为本地文件。
  • 新照片和作品继续只保存于当前浏览器。预设和定制一起自动保存，旧 v1 作品保留原有内容并补齐默认字段。

材质与款式 v0.5

保留写实小物与手工纸件的分工：四叶草改为带叶脉、轻微干燥斑纹和真实薄边的压叶；布偶统一为短绒棉布、可见缝线、黄铜挂环和低饱和小布贴，提供燕麦小熊与苔绿小兔，均为原创形象。眼镜提供琥珀 / 鼠尾草 / 香槟细框，发圈提供蓝格 / 藕粉 / 草绿，兰花提供奶油白 / 浅粉 / 奶油黄。

真实材质用有限的完整图片款式，不用全图染色破坏叶脉、玻璃和绒布的高光。程序化纸件与小装饰保留自由配色。默认组合使用中性色底、一个主色、少量点缀；背景、内衬与物件不同时争夺注意力。新增纸件置于底层。

本轮 9 张原始生成 PNG（2 张替换默认资产、7 张额外款式）保存在 tin-app/public/assets/variants/，通过内置 image_gen 生成，原始像素不做后处理。提示词、参考文件、原图路径、透明边界与 SHA256 见 tin-app/public/provenance/customization-generation.json。

分类改为「玩具挂件 / 随身物品 / 纸片票根 / 音乐游戏 / 小零件 / 花草贝壳」和「我的」。胶片归入纸片票根，火漆归入小零件。
