日期：2026-09-24。范围：本地 Chrome 桌面、390 × 844 触摸模拟、320 / 768 / 1440 px 视口。**未使用真实手机，不将模拟结果当作真机性能。**

开盖另作 **101 个角度采样**：盖体及盖内物件顶点没有进入底盘内部包围区域（x ±69、y ±44、z 0.5–19 mm）。关键角度 0 / 0.25 / 0.5 / 0.75 / 1 截图位于上级 `output/playwright/hinge-*.png`，已目视检查；这是保守顶点检查，不是完整碰撞求解器。铰链连接处允许正常装配接触。

开发游戏技能的输入循环使用其原客户端副本 `scripts/web_game_playwright_client.mjs`，替换为本机 Chrome 与项目 Playwright 依赖，并显式选择 `.stage canvas`，避免将抽屉中的高分辨率素材画布误当作游戏画面。原安装脚本引用另一个桌面项目依赖时未能启动浏览器，已终止该次测试。最终截图和状态见 `output/web-game/final-open/`。

## 尚未验收 / 已知边界

- 真实 iPhone / Android：浏览器手势、长按保存、音频解锁、系统分享、HEIC 兼容、30 FPS 连续互动。
- 同一 Wi-Fi 的真机连通性及防火墙；电脑当前地址 10.131.145.164，可能变化。
- 首次用户是否 30 秒理解、1–3 分钟完成：需要真实首次用户试用。
- 2.5D 小物是薄片，线材使用固定姿态，不做体积碰撞；连拍条以同一张照片生成三格。
- 全分辨率 PNG 的少量色边 / 毛边、合盖中接近侧视角的薄片观感，仍可后续精修。开盖材质反射会随角度变暗。
- IndexedDB 只保证同浏览器同来源恢复。浏览器清理、私密模式、设备空间不足可能丢失本地数据；UI 已提示保存状态和 PNG 备份。

## 界面简化修订

全屏 Three.js 桌面，固定底部木质长抽屉，无介绍页、侧栏、作品计数和装饰性文案。默认全部物件，个人照片与文字在「我的」；旋转、移位、移除只在选中物件后出现，尺寸与图层收在更多操作中。设置内保留名称、桌面、声音及显示偏好。旧作品结构和 IndexedDB 数据未清除。手机与桌面截图位于上级 output/playwright/desk-refined-*.png。

## 定制与操作简化 v0.5（当前行为）

本节覆盖历史 v0.4 的「随机保留已摆放私人内容」语义。

- 「随手抓」增加 3 件并保持原对象 ID / 内容 / 位置 / 配色；「换一盒」完整更换摆放和外观，不重复当前预设，保留照片库，一次撤销完整恢复先前的私人内容。五套成品图已重新导出，四叶草已替换为真实压叶。
- 七类物件的图片 / 资产变体均通过真实 UI 切换，并逐个比较 Canvas 输出，确认外观改变、位置 / 旋转 / 层级不变；纸胶带另验证条纹 / 波点 / 格纹及颜色。
- 叠放列表选择遮挡物件，上移 / 下移一层与最上 / 最下生效，不移动坐标；边界操作按钮禁用。
- 十类纸件 / 钥匙牌 / 火漆内容修改后 Canvas 确实变化；旅行画片和胶片 3 格照片来自本机上传，导出和刷新后仍保留引用。
- 清空弹出 alertdialog，取消无变化，确认后物件为零；照片素材和配色保持，一次撤销全部恢复。
- 320 / 390 / 1440 px 定制弹层完整在视口内；修正手机面板偏左与随机菜单被物件工具条遮挡。
- 正常流程无浏览器异常及控制台错误。截图、PNG 与报告位于 output/acceptance-customization/；最终输入 / 画布检查位于 output/web-game/customization-final/。
- 新生成 9 张 RGBA 原图，2 张替换默认四叶草 / 布偶，7 张额外款式。公共物件总数保持 36（18 AI + 18 程序），款式集中在单个物件菜单中，不增加抽屉按钮数量。完整生成提示词、参考路径和原图哈希见 public/provenance/customization-generation.json。
